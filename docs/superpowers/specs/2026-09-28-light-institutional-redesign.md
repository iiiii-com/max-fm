# 浅色机构研究 · 视觉重构规格

日期：2026-09-28
状态：已获用户批准

## 目标

把 `max-site` 从「黑底琥珀终端」重塑为「浅色机构研究」风格，同时：

1. 保留桌面端高密度（用户明确选择：桌面高密度 + 移动端重排）
2. 数字与图表成为质感的主要承载点
3. 所有改动不得影响数据正确性（36 项数据回归必须持续全绿）

## 不做的事

- 不引入彩色主色（研究类产品的权威感来自黑白灰 + 粗线）
- 不改图表的业务逻辑，只改取色来源
- 不重写页面结构（P2/P3 之后再说）

## 设计系统

### 色彩

| 角色 | 值 | 说明 |
|---|---|---|
| `--background` | `#fbfbfa` | 纸面暖白 |
| `--foreground` | `#1a1a1a` | 墨色 |
| `--card` | `#ffffff` | 卡片纯白，与纸面拉开 |
| `--surface` | `#f4f3f0` | 次级面 / 表格条纹 |
| `--border` | `#e2e0dc` | 发丝线 |
| `--border-strong` | `#1a1a1a` | 仅用于主标题下 2px 线 |
| `--muted` | `#6b6862` | 次要文字（白底对比度 ≥ 5.6:1） |
| `--up` | `#c0392b` | 涨 = 红（A 股惯例），比深底版更深 |
| `--down` | `#1e8449` | 跌 = 绿 |
| `--primary` | `#1a1a1a` | 强调色即墨色，不设彩色主色 |
| `--radius-*` | `2px` | 从 1px 改，1px 在浅底上显脏 |

保留 `.dark` 块作为暗色模式预留，但不再是默认。

### 字体

- 标题：`--font-serif`（Noto Serif SC / 思源宋体）→ 研报感
- 正文：Geist Sans + 系统中文（PingFang SC / 微软雅黑）
- 数字：IBM Plex Mono，**全局 `tabular-nums`**

### 图表

新建 `lib/charts/theme.ts`，ECharts 统一从此取色：

- 8 色分类色板（按浅底可辨识度排序）
- 涨跌一律用 `--up` / `--down`，不用系列色
- 移除随机 `color` 数组与随机 `animationDuration`（`/macro` 24 图混乱的根因）
- 轴线、标签、网格、tooltip 背景统一定义

## 执行阶段

| 阶段 | 内容 |
|---|---|

| P2 | `/macro` Tab 分组（总量/价格/需求/海外）+ 全局控制条 |
