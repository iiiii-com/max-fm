# 四大板块深化增强设计（2026-08-20）

> 基于 2026-08-19 四板块整合设计与危机重演上线后的反馈迭代。脑暴确认：4 个方向共 23 项增强。

## A. 危机重演增强（7 项，全选）

### A1 当时真实龙头股
- 6 场 major 危机各加 3-5 只当时真实龙头股（真实 secid + 简称 + 一句话角色说明）
- Crisis 类型新增 `stocks?: Array<{ name: string; secid: string; role: string }>`
- 引擎 K 线图支持视角切换：主市场指数 / 各龙头股（fetchKline 同源 API）
- 2008：花旗 100.C、雷曼兄弟（已退市，标注历史）、AIG、通用汽车；2015：中国平安 1.601318、中信证券 1.600030、乐视网（退市标注）；2020：波音 100.BA、美联航 100.UAL、迪士尼 100.DIS；1929：美国钢铁、通用汽车（快照数据）

### A2 多维数据曲线
- Crisis 新增 `vixData?: Array<{ date: string; value: number }>`（VIX 或波动率指数月度/关键时点数据）
- 引擎 K 线下方二级图表：恐慌指数 VIX 曲线（与主图联动时间轴）
- 节点卡显示该节点区间涨跌幅 + 波动率变化

### A3 当年新闻头条流
- CrisisNode 新增 `news?: string[]`（1-2 条真实历史标题，如 2008-09-15 "雷曼兄弟申请破产保护"）
- 节点卡内新闻头条区块（报纸风格：衬线字体 + 引号）

### A4 时间线导航
- 顶部缩略时间线：全部节点 date 等距排列，当前节点高亮，可点击跳转任意节点
- 已完成节点打勾标记（含 quiz 得分标记）

### A5 暴跌动画 + 恐慌仪表盘
- 进入下一节点时：若区间跌幅 <-3%，触发暴跌动画（数字红色跳动 + 图表闪动 1.2s）；涨幅 >+3% 绿色
- 恐慌仪表盘：0-100 指针仪表（基于 VIX/跌幅映射），每节点更新，超过 80 红色警报
- 无 echarts gauge 依赖，用 SVG 弧线实现（避免引入新依赖）

### A6 危机 + 时代背景对照
- Crisis 新增 `context?: Array<{ date: string; event: string }>`（危机期间全球大事：政策/地缘/科技/文化）
- intro 阶段展示"当时的世界"时间线卡片；节点推进时同步展示对应日期附近背景事件

### A7 结算页收益对比折线图
- 折线图：你的 NAV 曲线 vs 主市场指数归一化曲线 vs "巴菲特式操作"（满仓-50% 现金策略模拟曲线）
- 用 echarts line，替代纯文字对比

### B3 多资金方向

### B4 板块展开个股资金流排行

### B5 龙头股精细详情

### B6 板块行内嵌龙头代表股
- 每行右侧龙头列（与 B5 联动，B5 的展示形式）

### D1 省 → 代表城市卡片

### D4 城市数据榜单
