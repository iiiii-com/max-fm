## 1. 工具箱 · 财务趋势工具（FinancialTrendsTool）

**定位**：研究体系工具箱新增「财务三表可视化」——营收/净利/毛利率/ROE 趋势。

**数据源**：
- 主源：东方财富 F10 财务摘要接口（`push2.eastmoney.com/api/qt/stock/get` 扩展或专门财务接口）
- 备用：新浪财务摘要
- 若接口不可用：明确标注「财务历史数据待接入」（不造假），展示已核验的当前财务（PE/PB/EPS，已有 fundamentals）

**组件**：`components/gmrds/FinancialTrends.tsx`（client）
- 标的选择（复用 LabStandalone 标的列表模式）
- ECharts 多序列折线：营收 / 归母净利（双轴：亿元）+ 毛利率 / ROE（副图）
- 周期：近 5 年（年报）· 近 8 季度（季报）切换
- 图注：数据源 + 口径说明

**验收**：选茅台显示真实营收/净利趋势；接口失败时显示待接入标注而非空白；tsc 0。

## 2. 工具箱 · 批量扫描（BatchScanner）

**定位**：自选股/预设股票池一键批量扫描——信号（买卖点）+ 估值 + 评分汇总。

**数据源**：`/api/stock/kline`（多源）+ `rule-engine.ts scanSignals` + `/api/stock/fundamentals`

**组件**：`components/gmrds/BatchScanner.tsx`（client）
- 股票池：预设（茅台/宁德/招行/比亚迪/腾讯/阿里…）+ 自选（localStorage watchlist）选择
- 并行拉取 K 线 → scanSignals → 汇总表格：标的 / 最新价 / 涨跌 / 信号数 / 最近信号 / PE / 估值结论
- 表格按信号数/涨跌排序，行点击跳转深度页 `/stock/[secid]`
- 上限 12 只（免费源频率限制）

**验收**：6-12 只标的并行扫描出表；信号/估值真实；点击下钻。

---

## 3. 市场 · 指数详情（IndexDetail）

**定位**：大盘指数卡片/详情展开——成分股、行业权重、估值分位。

**数据源**：
- 成分股：东财指数成分接口（`push2.eastmoney.com/api/qt/clist/get?fs=b:MKxxxx`）——本机可能受限，标注线上可用
- 行业权重：自算（成分股行业分类）或接口
- 估值分位：指数 PE 历史（东财接口）或标注待接入

**组件**：`components/IndexDetailPanel.tsx`（client，嵌入 /market 大盘指数区）
- 点击指数卡「详情」→ 展开面板
- 成分 Top10（名称/权重/涨跌）+ 行业分布 mini 条形 + 估值分位条
- 数据受限项灰显「数据源受限，线上可用」

**验收**：上证/沪深300 显示成分与权重（线上）；本机受限时友好降级。

## 4. 市场 · 市场宽度（MarketBreadth）

**定位**：涨跌家数 / 涨跌停 / 成交额——市场整体温度。

**数据源**：东财涨跌家数统计接口（`push2.eastmoney.com/api/qt/ulist.np/get` 全市场 or 专用统计接口）；本机受限时标注

**组件**：`components/MarketBreadth.tsx`（client）
- 卡片组：上涨 / 下跌 / 平盘家数、涨停 / 跌停、两市成交额、红绿比
- 迷你图：近 20 日涨跌家数趋势（面积图）
- 温度判定：上涨占比 >60% 偏热 / <40% 偏冷

**验收**：真实家数统计（线上）；本机受限友好降级；温度判定逻辑可解释。

---

## 5. 市场 · 技术面标注（TechLevels）

**定位**：个股 K 线自动标注支撑/压力位、关键均线价格。

**数据源**：已有多源 K 线 + `indicators.ts`（SMA 已有）

**组件**：`components/charts/TechLevels.tsx`（client，作为 AnnotatableChart 的辅助层或集成到 StockSearch 详情）
- 自动计算：近 60 日高/低点（压力/支撑）、MA20/60 当前值、近期密集成交区
- K 线图上以虚线标注支撑/压力 + 右侧价格标签
- 与画线标注共存（TechLevels 为只读辅助，不干扰用户画线）

**验收**：茅台等显示支撑/压力虚线 + 均线价格；与画线/缩放平移兼容。

## 6. 产业 · 节点行情（ChainNodeQuotes）

**定位**：产业链节点（公司）挂实时行情——涨跌/价格一眼可见。

**数据源**：`/api/quotes`（已有，含 A 股指数/个股？需确认个股覆盖）→ 若缺个股，扩展 quotes API 或新增 `/api/chain/quotes`（东财/新浪个股行情）

**组件**：`components/industry/ChainNodeQuotes.tsx`（client，嵌入产业链详情页）
- 链上公司列表行：名称 / 最新价 / 涨跌幅（红涨绿跌）
- 点击行 → 深度页 `/stock/[secid]`
- 数据受限灰显

**验收**：产业链详情页公司行带真实涨跌；点击下钻。

## 7. 历史 · 事件筛选（TimelineFilter）

**定位**：历史时间线按朝代/类型筛选，聚焦查看。

**数据源**：`lib/data/history.ts`（已有 HISTORY_EVENTS，含类型字段）

**组件**：`components/history/TimelineFilter.tsx`（client，嵌入 /history）
- 筛选 chips：朝代（先秦/秦汉/唐宋/明清/近代…）+ 类型（政治/经济/战争/文化/科技…）
- 多选 + 高亮计数；筛选联动时间线渲染

**验收**：筛选生效、计数正确、与现有时间线无缝衔接。

## 8. 历史 · 搜索跳转（TimelineSearch）

**定位**：事件关键词搜索 + 年代快速跳转。

**数据源**：`lib/data/history.ts`

**组件**：`components/history/TimelineSearch.tsx`（client）
- 搜索框：关键词匹配事件标题/简介（模糊）
- 结果列表（事件名 + 年份），点击滚动定位到时间线该事件（scrollIntoView + 高亮）
- 年代跳转：世纪选择器（公元前5世纪~21世纪）直接定位

**验收**：搜索"安史之乱"定位到对应事件；年代跳转滚动正确。

## 技术要点（横切）

1. **数据真实性**：所有新增数据必须真实可溯源或标注「待接入/受限」；不造假（沿用全站原则）
2. **多源容错**：东财不可达时降级新浪/腾讯或友好标注（复用 index-kline.ts / stock-kline 三级源）
3. **组件复用**：VizBoundary 错误边界、InteractiveKlineLab、EChart、涨红跌绿色板
4. **响应式**：新组件移动端不破版（grid 自适应 / overflow-x-auto）
5. **验证**：tsc 0 + 浏览器实测（agent-browser）+ 冷验证 0 错误 + 页面 200

## 实施顺序建议

1. **工具箱两块**（财务趋势 + 批量扫描）——数据基础最好
2. **市场三块**（指数详情 + 市场宽度 + 技术面标注）——复用行情链路
3. **产业节点行情**——链路短
4. **历史两块**（筛选 + 搜索）——纯前端、零风险
