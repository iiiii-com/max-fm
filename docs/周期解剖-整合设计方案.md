# 「全球股市完整周期解剖」整合设计方案

> 目标：把《全球股市完整周期系统化解剖》一文的内容整合进 max-site，并以可视化方式呈现。
> 本文档回答六项说明，并先交代一个**必须先决策的数据问题**。

---

## 0. 前置问题：文本数值与站点既有真实数据冲突（须先定调）

max-site 的立站原则是 **数据必须真实、可溯源、可验证**。因此交付前必须核对。

用站点自带的 `data/sh-index.json`（8536 根上证真实日线）复算 A 股历次牛市涨幅，与文本对照：

| A 股牛市 | 文本所写 | 站点按真实日线复算 | 偏差 |
|---|---|---|---|
| 1990.12–1992.5 | 1392% | **1329%** | +63 |
| 1996.1–1997.5 | 194% | **186.6%** | +7.4 |
| 1999.5–2001.6 | 114% | **98.6%** | +15.4 |
| 2005.6–2007.10 | 513% | **489%** | +24 |
| 2008.10–2009.8 | 109% | **95.9%** | +13.1 |
| 2014.3–2015.6 | 162% | **163.7%** | −1.7 |

**6 轮中 5 轮偏高，且偏差方向一致（除 2014 外全部虚高）**，属于系统性偏差而非四舍五入。另有：

- 起止日不一致：文本「2014.3 起」，站点为 `2013-06-25 ~ 2015-06-12`。
- 覆盖范围不一致：文本列 6 轮牛市，站点收录 **11 轮**（含 2016 白马牛、2019 结构牛、2024 924 行情）。
- 文本自身内部矛盾：
  - 「1929 年以来 25 次牛市、平均 32 个月」／「二战后平均 56 个月」／「1957 年以来平均 4.8 年(≈58 个月)」三者互斥；
  - 「25 次牛熊」与「1957 年以来共十轮牛熊」并存。

**结论与建议处置：**
1. **A 股数值一律以站点复算值为准**（可由 `sh-index.json` 一键复现，可验证），文本数值仅作参考、不直接上站。
2. **美股长历史数值（1929 年以来的牛熊、崩盘）站点目前没有数据支撑**，文本亦未给出来源。
   建议先补数据源（见 §5），数据到位前**只做框架呈现，不放具体数值**；或明确标注「待核验」。
3. **论述性内容（驱动引擎、六阶段闭环、六大规律）不是数值数据**，作为**研究框架/观点**呈现，
   与数据图表在视觉上明确区分（不同底色与「观点」标识），避免读者把分析框架误当既成事实。

> 这一处置与站点既有做法一致：`/analysis/bullbear` 末尾就有「数据来源与统计口径」小节。

## 1. 内容包括哪些数据与信息

按**可验证程度**分三层，决定各自的呈现方式与位置：

### A 层 · 站点已有真实数据（可直接用，可复现）
| 内容 | 现有来源 | 对应文本章节 |
|---|---|---|
| A 股 21 段牛熊（起止/天数/涨跌幅/高低点） | `data/bull-bear-raw.json`（由日线复算） | 1.2 |
| 上证 8536 根日线（1990-12-19 起） | `data/sh-index.json` | 1.2 / 1.4 |
| 历次崩盘的最大回撤与下跌时长 | 可由 `sh-index.json` 复算 | 1.4 |
| 美股、全球指数近期行情 | `data/us-market.json` + 腾讯/东财/新浪接口 | 1.1（仅近 20 年） |
| 历史危机事件（205 条，含分类/时间/影响） | `data/history-events.json` | 1.3 / 3.1 |

### B 层 · 需要新引入外部数据（当前站点没有）
| 内容 | 需要的序列 | 建议来源 |
|---|---|---|
| 美股 1929 年以来历次牛熊 | 标普500 / 道指 **长历史日线** | Shiller 数据集、FRED、Stooq |
| 美股历次崩盘的跌幅/时长/修复时长 | 同上 | 同上 |
| 巴菲特指标、席勒 CAPE | 长历史估值序列 | Shiller 官方数据集（提供 Excel/CSV） |
| 美国信用利差（牛市终结信号） | ICE BofA 高收益利差 | FRED（免费） |

### C 层 · 论述性框架（非数值，可直接采用）
- 2.1 美股四大引擎（利率 / 盈利 / 回购 / 被动资金）
- 2.2 A 股四大引擎与三阶段演进（政策 / 资金 / 制度 / 叙事）
- 2.3 中美牛市模式对比（7 个维度）
- 3.1 周期闭环六阶段
- 3.2 驱动逻辑链条（正向强化 / 断裂条件）
- 3.3 终结预警信号（美股 3 条、A 股 4 条）
- 4.1–4.6 六大规律

## 2. 目标受众与使用场景

| 受众 | 场景 | 对设计的要求 |
|---|---|---|
| **进阶个人投资者（主要）** | 判断当前处于周期什么位置、复盘历史 | 当前定位要醒目；历史可比 |
| 研究型 / 半专业用户 | 核对数据、追溯来源 | 每个数字可查来源与口径 |
| 财经内容创作者 | 取用图表与结论 | 图表可读、可截图 |
| 入门学习者 | 理解牛熊机制 | 有引导路径、术语可解释 |

**场景主线**：进入 → 看到「我们现在在哪」（周期定位）→ 想看「历史上类似阶段发生了什么」→ 深入「为什么会这样」（驱动机制）→ 最后「怎么识别终结」（预警信号）。

即四步递进：**定位 → 对照 → 归因 → 预警**。

沿用已确认的取向：**桌面保持专业信息密度，移动端给精简视图**。

## 3. 网站整体结构与页面划分

**核心判断：文本的 §1（数据）已被现有模块覆盖，§2–§4（框架）才是新增价值。**
因此不另起炉灶，而是「复用 + 补一层」。

### 复用现有
```
/history                    历史演进（已有 tabs）
  ├─ tab=bullbear           A股牛熊（21 段，真实数据）
  ├─ tab=waves              康波周期
  └─ tab=crisis             危机重演引擎（CrisisEngine / CrisisImpactTable）

/analysis/bullbear          牛熊全景分析（已有 4 节）
  ├─ 一、A股与美股 K 线对比
  ├─ 二、A股牛熊关键事件 · 四层拆解
  ├─ 三、美股同期对比 · 五维对照
  └─ 四、牛熊全景 · 全维度量化
```

### 新增（建议）
```
/analysis/cycle-anatomy     周期解剖（新页，承载 §2–§4 框架内容）
  ├─ 一、四大引擎          中美各一套，并列对照
  ├─ 二、周期闭环六阶段     环形 + 阶段卡片
  ├─ 三、终结预警信号       美股 3 / A股 4，可交互信号盘
  └─ 四、六大规律           逐条配图

/analysis/bullbear          追加两节（数据向）
  ├─ 五、牛熊「涨幅×时长」散点对照
  └─ 六、崩盘「下跌时长 vs 修复时长」对照
```

**不新增导航入口**（遵守此前确认的「不改全站导航」），从 `/analysis/bullbear` 与
`/history` 以内链互达；`/cycle` 现为重定向页，可指向新页。

## 5. 数据来源与更新方式

| 数据 | 来源 | 更新方式 |
|---|---|---|
| A 股牛熊/崩盘 | `sh-index.json` 复算 | **构建期固化**（脚本生成 JSON），历史不变 |
| 美股长历史 | Shiller / FRED / Stooq | 一次性引入 → `data/us-long-history.json`，构建期读取 |
| 实时行情 | 腾讯 gtimg / 东财 / 新浪（现有） | 运行时接口，5 分钟～1 天缓存 |
| 估值指标（CAPE/巴菲特指标） | Shiller 官方 CSV | 季度更新（数据本身季度频率） |
| 论述框架 | 随代码版本 | 与代码同版本管理 |

**新增脚本**：`scripts/build-cycle-data.ts` —— 从 `sh-index.json` 复算
「崩盘最大回撤 / 下跌时长 / 修复时长」，输出 `data/cycle-crashes.json`，
保证每个数字都能被复现（满足可溯源要求）。

## 6. 视觉风格与响应式

**风格**：完全沿用站点既有终端美学，不引入新语言。
- 深色底 `#050505` / 卡片 `#0a0a0a` / 边框 `#292929` / 次要文字 `#8a8a8a`
- 主色琥珀 `#f28c00`；涨 `#ff4d4f`、跌 `#00c176`（**A 股惯例，红涨绿跌**）
- 等宽字体（IBM Plex Mono + 中文回退），数字 `tabular-nums` 纵向对齐
- **数据区与观点区视觉分区**：数据用常规卡片；框架/观点用左侧琥珀竖线 + 「研究框架」角标

**响应式**：
- 桌面：多列网格，信息密度保持专业级
- 移动：复用已建好的 `CollapsibleOnMobile`（`md:!max-h-none`，桌面零影响），
  长表格默认折叠；图表高度自适应，散点图在窄屏降低标签密度
- 复用 `components/ui-state.tsx` 统一加载/空/错误三态

**无障碍**：图表补文字摘要（`aria-label`）；色觉障碍用形状/标签冗余编码，不单靠颜色。
